Some setup notes

  • Google DNS:
    8.8.8.8
    8.8.4.4
    2001:4860:4860::8888
    2001:4860:4860::8844
  • Dock, show/hide speed:
    defaults write com.apple.dock autohide-time-modifier -int 0
    defaults write com.apple.dock autohide-delay -float 0
  • Menubar, reduce spacing between items:
    defaults -currentHost write -globalDomain NSStatusItemSelectionPadding -int 10
    defaults -currentHost write -globalDomain NSStatusItemSpacing -int 10
  • Screenshots, change format and no shadow:
    defaults write com.apple.screencapture type jpg
    defaults write com.apple.screencapture disable-shadow -bool TRUE
  • Application, new instance:
    open -n /Applications/Safari.app
  • Python, pip:
    pip install --upgrade pip
  • Python, libraries:
    pip install numpy pandas matplotlib scipy bambi pymc pymc-bart kulprit nutpie scikit-learn jupyterlab notebook voila preliz graphviz pip-review
  • Python, pip freeze:
    pip freeze
  • Python, pip-review:
    pip-review
